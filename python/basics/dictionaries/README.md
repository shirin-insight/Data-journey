# Employee Sales Performance Analysis

## Project Overview
This project analyzes employee sales performance using Python dictionaries, loops, and conditional statements.

The goal is to evaluate sales performance, compare actual sales with targets, and identify high- and low-performing employees.

## Data Description
**Note:** All data used in this project is fictional (synthetic) and created for educational and practice purposes. It does not represent real employees or actual company performance.

The dataset includes:
- Employee names
- Sales figures
- Sales targets
- Salaries

## Analysis
The script performs the following tasks:
1. Calculates total sales.
2. Calculates average sales per employee.
3. Identifies employees who achieved their sales targets.
4. Finds the employee with the highest sales.
5. Identifies employees with sales below 40 units.

## Python Concepts Used
- Dictionaries and nested dictionaries
- For loops
- Conditional statements (`if`)
- Variables and arithmetic operations
- The `len()` function

## How to Run
Run the following command:

```bash
python employee_sales_analysis.py
```
